Executables and networking

Node groups

Arguments are a JSON array of strings, e.g. ["--ingress-sockets", "TCP:port=0"]. Use ${instance} for the 1-based replica number, ${index} for the 0-based global node index, and ${workspaceFolder} for the workspace path. Split groups to give individual nodes different arguments. Ports and capabilities use the controls above.
